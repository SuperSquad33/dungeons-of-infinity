# Branches

* `main`
  * *Community Edition* maintaining of the base code with bugfixes and mod support
  * Intended to compile, run & build on the latest version of [GameMaker](https://gamemaker.io)
  * Should be stable code
  * Will eventually be ported to *GMRT* target

* *feature branches*
  * Development branches of bleeding-edge ideas
  * Likely unstable code

* `stable/1.2.1`
  * Source code given to the community by Justin Bohemier
  * Uses *GMS2* target
  * See [ReadMe](README.md#gamemaker-versions) for GameMaker IDE & Runtime versions
